# Video Downloader UI 重设计说明

## 定位

本轮只定义新的界面结构、导航路径与信息层级，不涉及技术实现细节。目标是把当前“解析、确认、下载、回看”的主链路收拢成更清晰的一条工作流。

## 导航结构

一级导航调整为 3 个入口：

1. `下载`
2. `资源库`
3. `我的`

不再把“已完成”单独当成一级页面，而是并入 `资源库` 统一承接。

## 页面清单

### 1. 下载

作为默认首页，承担高频启动动作：

- 粘贴链接并通过单一主动作“开始解析”进入流程
- 查看今日完成、排队中的摘要状态
- 查看最近一次解析与队列概览

页面风格强调“工具台”，把主操作放在最显眼位置。

### 2. 资源确认页

作为解析完成后的唯一确认界面，承担：

- 预览当前资源
- 浏览同一链接下的多资源结果
- 确认标题、格式与保存提示
- 执行“下载当前”或“下载全部”

该页强调“先确认，再下载”，避免用户直接进入复杂列表。

### 3. 资源库

作为统一内容中心，承接：

- 进行中任务
- 已完成内容
- 解析记录

通过分段切换控制视图，避免多个历史入口并存。

### 4. 详情页

作为单条任务或资源的诊断页，重点展示：

- 资源状态
- 资源预览
- 保存路径
- 文件状态
- 异常提示
- 底部操作

该页不承担列表职责，只服务单条记录处理。

### 5. 我的

承接低频设置与支持信息：

- 命名规则
- 网络策略
- 保存位置
- 通知偏好
- 帮助与诊断入口

避免把低频配置混入下载主链路。

## 信息架构原则

- 首页只保留“开始动作 + 摘要状态”。
- 解析结果统一进入确认页，不直接散落到历史页。
- 历史相关内容统一收口到资源库。
- 单条资源的查看、排障、删除统一进入详情页。
- 设置与帮助放在“我的”，不占据主操作区。

## 视觉方向

采用“深海工具感”：

- 主色：`#0F5D91`
- 强调色：`#19B7A5`
- 浅背景：`#F4F7FB`
- 卡片白底 + 大圆角 + 轻阴影
- 标题使用 `Geist`
- 正文字体使用 `Funnel Sans`
- 数据数字使用 `Geist Mono`

整体目标不是做内容社区感，而是做“稳定、清晰、可信”的下载工具体验。

## 当前设计稿位置

Pencil 设计稿当前包含以下页面：

- `下载 · 主工作台`
- `资源确认页`
- `资源库`
- `详情页`
- `我的`

后续进入实现阶段时，应以这份导航结构和页面职责划分为准，而不是继续沿用旧的多入口历史结构。
