## 1. 手册定位
本手册用于维护阶段的“怎么排障、怎么回归、怎么发布”，与需求/设计文档配套使用。

## 3. 常见改动优先级
1. 先确认问题属于 UI、parser、download 还是持久化边界。
2. 解析/下载问题优先改 `parser/`、`download/`、`domain/usecase/`。
3. 当前主 UI 问题优先改 `ui/redesign/`。
4. 旧 `ui/screen/history/` 可作为历史实现参考，但不要默认把它当当前入口。
5. 若涉及未来方案，请先确认 `docs/plans/` 是否已真正落地，不要直接按方案假设现状。

## 4. 关键排障路径
### 4.1 解析异常
- 查看 `ParseLinkUseCase`、`WebParserGateway`、`YtDlpParserGateway` 日志。
- X 相关先检查 Cookie：`auth_token`、`ct0`。
- kstore 链接先确认 hash 可正常解码为 JSON。
- X 性能定位优先看：
  - `parseXFast ... cost=...`
  - `parseXStatusFast branch=... hit=... cost=...`
  - `parseTwitterFx mirror=... hit=... cost=...`

### 4.2 下载异常
- 查看 `AndroidDownloadGateway` 预检、分片重试、落盘校验日志。
- 若为加密 m3u8，重点检查：
  - `#EXT-X-KEY` 的 `METHOD / URI / IV` 是否解析成功
  - key 拉取是否 200
  - 是否触发 `unsupported m3u8 key method`
- 若反馈“成功但不可播放”，优先确认是否被有效性校验判失败并删除。

### 4.3 UI 交互异常
- 当前导航入口：`ui/redesign/navigation/RedesignNavHost.kt`。
- 下载页：`ui/redesign/download/DownloadScreen.kt` + `DownloadViewModel.kt`。
- 资源确认页预览：`ui/redesign/parse_result/ParseResultScreen.kt` + `MediaPreview.kt`。
- 资源库管理：`ui/redesign/library/LibraryScreen.kt` + `LibraryViewModel.kt`。
- 详情页打开/删除/重试：`ui/redesign/detail/DetailScreen.kt` + `DetailViewModel.kt`。
- 我的页与 X Cookie 入口：`ui/redesign/profile/ProfileScreen.kt` + `RedesignNavHost.kt`。

## 5. 回归最小集
每次涉及解析/下载改动至少执行：
- 抖音文案解析 1 条 + 下载 1 条
- X 普通视频（Cookie 有效）1 条
- kstore hash 链接（`bluegay` 或 `xgaymv`）1 条
- AES-128 m3u8 1 条，验证 key + 分片解密
- 非 AES-128 m3u8 1 条，验证不支持提示
- 同标题重复下载 2 次，验证 `(1)` 命名
- 资源库内验证：进行中 / 已完成 / 解析记录
- 资源确认页验证：视频点击预览区原地播放
- 已完成列表和详情页验证：封面静态展示，不触发原地播放
- 我的页验证：X Cookie 设置可进入

## 6. 构建与发布
```powershell
.\环境一键配置.ps1
.\gradlew.bat :app:testDebugUnitTest
.\gradlew.bat :app:assembleDebug
```

APK：`app/build/outputs/apk/debug/app-debug.apk`

## 7. 清理策略
可安全清理（可再生）：
- `app/build/`
- 临时目录（若存在）
- 根目录 `tmp_*.png`
- 根目录调试数据库：`*.db`、`*.db-shm`、`*.db-wal`
- 本机工具配置：`.claude/`

不建议频繁清理：
- `.gradle/`（会导致依赖重复下载）
- `.idea/`（IDE 工程配置）
