# 安卓本地视频下载 App 需求说明（当前基线）

> 文档版本：v1.6.0
> 最后更新：2026-05-07

> 说明：本文档只描述当前已实现基线；`docs/plans/` 下的重构方案不属于本文范围。

## 1. 目标
- 面向个人自用场景，提供抖音、X 与 kstore hash 链接解析、本地下载与历史管理。
- 不依赖自建后端，不依赖电脑 sidecar 或额外设备，数据仅存本机。
- 重点保证：可解析、可下载、可播放、可定位失败原因。
- 当前交互入口为新 UI：下载工作台、资源库、信息中心。

## 2. 范围
### 2.1 在范围内
- 链接/分享文案输入与 URL 提取。
- 抖音与 X 链接解析、可下载格式展示。
- 抖音图文、动图/实况图通过 App 内签名详情接口补充解析真实视频资源。
- 抖音 Cookie 手动设置，用于提高抖音详情接口解析成功率。
- X 图文混合、多视频链接解析；同一视频多清晰度只保留一个推荐/默认视频项，不同视频需分别保留。
- X 状态链接解析采用并行分支策略以降低等待时延。
- `kstore.vip/*.html#...`（如 `bluegay/xgaymv`）hash 解码解析。
- 下载任务创建、状态同步、失败重试。
- 普通 m3u8 下载与 `AES-128` 加密 m3u8 下载。
- 资源库管理：进行中 / 已完成 / 解析记录三栏。
- 进行中、已完成与解析记录支持长按进入管理、全选、删除。
- 通过“下载全部”创建的同一图集任务在资源库内按同一 `parseRecordId` 聚合展示。
- X Cookie 手动与网页登录回填。
- 抖音 Cookie 手动保存。
- 下载结果有效性校验与异常文件自动清理。
- 下载完成通知开关由我的页真实控制。
- 已完成详情支持 App 内图片查看器与 Media3/ExoPlayer 视频播放器。

### 2.2 不在范围内
- 云端账号与多端同步。
- iOS 支持。
- 面向上架的商业化流程。
- 非 `AES-128` 的加密 m3u8（如 `SAMPLE-AES`）。
- `TaskGroup + TaskItem` 任务模型与帖子级多媒体解析模型。
- 抖音动图保存为系统相册可识别的原生 vivo 实况图。
- 生成实验性 Motion Photo 或额外封面图片文件。

## 3. 核心功能需求
### 3.1 解析与格式展示
- 支持从抖音分享长文本中提取真实链接。
- 抖音图文中存在视频/动图资源时，应优先展示和下载对应 `mp4` 动态资源。
- 抖音动图/实况图类资源下载时只保存一个 `_动态.mp4` 文件；封面只用于 App 内预览，不单独落盘。
- 支持 `kstore.vip/*.html#...` 变体 Base64 hash 解码并提取真实媒体地址。
- 解析结果至少展示：分辨率/扩展名、可下载性。
- 解析结果页支持单项预览与多项横向切换。
- 解析结果页主展示区按原比例最大展示图片/视频封面；缩略区只负责展示与选择。
- 解析结果页视频只能通过主展示区播放按钮进入内置播放器，点击封面其他区域不触发播放。
- 已完成列表只展示封面，图集/合集项右上角显示合集标识。
- 已完成详情按纵向媒体流展示；图片点击进入 App 内查看器，视频点击播放按钮进入内置播放器。
- 可获取时展示：时长、大小、码率。

### 3.2 下载与文件管理
- 创建任务后进入下载队列，支持重试与取消。
- 下载队列卡片显示进度条与百分比。
- 同名文件自动重命名：`标题(1)`、`标题(2)`…
- 下载成功后文件可被系统媒体库识别。
- 异常结果自动判失败并删除，不进入“已完成”。
- 同一集合内部分失败时，已完成集合只展示成功内容；下载列表仍保留失败状态。
- 失败集合详情的重新下载只重试当前集合内失败项，成功后追加到对应已完成集合。

### 3.3 m3u8 行为
- 普通 m3u8：分片并发下载、顺序写入合并。
- 加密 m3u8：支持 `#EXT-X-KEY` 且 `METHOD=AES-128`。
- key 下载失败、IV 非法、解密失败需返回可读错误。
- App 内视频播放器需支持 HLS/m3u8 播放。

### 3.4 资源库
- 资源库包含进行中、已完成、解析记录三栏。
- 三栏切换按钮固定悬浮在底部导航上方，不随内容滚动。
- 无任务时显示空状态，不展示假任务卡片。
- 进行中任务可进入详情，支持暂停、恢复、删除、重试等操作。
- 进行中栏支持长按进入管理模式。
- 已完成栏支持长按进入管理、多选、全选、删除。
- 已完成图集按同一 `parseRecordId` 聚合为同一条记录，详情页按媒体列表展示。
- 解析记录展示完整列表，支持点击展开摘要信息、长按管理、多选、全选、删除。

### 3.5 我的页面
- 我的页提供常用设置入口。
- X Cookie 设置从我的页进入，复用旧设置页与网页登录回填能力。
- 抖音 Cookie 设置从我的页进入，保存后供抖音详情接口解析使用。
- 下载完成通知开关从我的页进入并持久化，关闭后不发送下载完成通知。

## 4. 非功能需求
- 稳定性：网络波动时不崩溃，并提供可读错误提示。
- 可维护性：业务规则集中在 UseCase/Gateway，UI 不写数据一致性逻辑。
- 隐私：Cookie 与历史仅本地保存，不上传服务器。
- 性能：m3u8 下载需支持受控并发、连接复用与退避重试。
- 可观测性：X 解析链路需输出分支耗时日志，便于定位慢点。

## 5. 验收基线
- 抖音普通视频可稳定解析并下载。
- 抖音图文、动图/实况图中存在视频资源时，可解析并以单个 `_动态.mp4` 保存。
- X 普通视频在 Cookie 有效时可解析并下载。
- `kstore.vip/*.html#...` 链接可解析出真实下载地址。
- `AES-128` 加密 m3u8 可下载并播放。
- 下载队列卡片显示进度条。
- 资源库内可完成进行中 / 已完成 / 解析记录三类视图管理。
- X 图文混合或多视频链接可展示多个不同媒体项；同一视频不同清晰度不会重复展示。
- 资源确认页视频只通过播放按钮进入 App 内播放器；缩略区和封面非按钮区域不触发播放。
- 已完成详情中图片/视频不跳转系统相册，均在 App 内查看或播放。
- 下载完成通知开关关闭后不发送完成通知，重新开启后恢复。
