# 失败场景回归测试清单（当前实现对齐）

> 文档版本：v1.4.0
> 最后更新：2026-05-03

## 1. 解析链路
### 1.1 抖音分享文案
- [ ] 粘贴整段抖音分享文案可提取真实链接。
- [ ] 文案含多段无关文本时，仍可命中链接。

### 1.2 X 普通视频
- [ ] Cookie 有效时可解析。
- [ ] Cookie 失效时有明确提示，不进入空白状态。
- [ ] `status` 链接解析耗时稳定（并行分支策略生效，无明显串行长等待）。
- [ ] 日志可看到分支耗时：`parseXFast`、`parseXStatusFast`、`parseTwitterFx mirror`。

### 1.3 kstore hash 链接（`*.html#...`）
- [ ] `bluegay.html#...` 可解析出真实 `m3u8/mp4` 地址。
- [ ] `xgaymv.html#...` 可解析出真实 `m3u8/mp4` 地址。
- [ ] 尾部存在额外 `#` 时仍可解析。

## 2. 下载链路
- [ ] 可下载项可正常入队。
- [ ] 失败任务可重试。
- [ ] 异常文件（空文件/文本内容）自动删除并归为失败。
- [ ] 资源库“进行中”卡片持续显示真实进度，不展示假任务卡片。
- [ ] 删除进行中任务时，后台 DownloadManager / 内部 m3u8 任务同步取消。

## 3. 资源确认页
- [ ] 图片集解析后缩略图按真实数量横向展示，无灰白占位和不可点击 `+n`。
- [ ] 单个资源缩略图居中显示。
- [ ] 视频资源可在资源确认页大预览区点击后原地播放。
- [ ] 返回下载页后无视频 Surface / 按钮残影。
- [ ] “下载全部”创建的同一图集任务共享同一 `parseRecordId`，资源库已完成栏聚合为一条。

## 4. m3u8 专项
### 4.1 普通 m3u8
- [ ] 分片下载过程中进度持续推进，无长时间停滞。
- [ ] 下载完成视频可正常播放，未出现顺序错乱。

### 4.2 加密 m3u8（AES-128）
- [ ] `#EXT-X-KEY:METHOD=AES-128` 链接可成功下载并播放。
- [ ] key 拉取失败时错误提示可读。
- [ ] IV 为空时可按分片序号生成默认 IV 并正常下载。
- [ ] 非 `AES-128`（如 `SAMPLE-AES`）返回明确不支持提示。

## 5. 资源库管理
### 5.1 进行中
- [ ] 无任务时居中显示“暂无下载任务”，不展示假卡片。
- [ ] 点击进行中任务进入真实详情页。
- [ ] 详情页“删除”会取消后台任务并删除数据库记录。

### 5.2 已完成
- [ ] 已完成以卡片形式展示，比例与设计一致。
- [ ] 已完成列表封面只静态展示，点击卡片进入详情，不原地播放。
- [ ] 已完成详情页封面只静态展示，不原地播放。
- [ ] 长按单项可进入管理模式并自动选中。
- [ ] 管理模式支持全选/取消全选与删除。
- [ ] 图集详情中每张图片使用自己的预览源，不全部显示第一张封面。
- [ ] 点击“打开内容”可通过系统应用浏览图片或播放视频。

### 5.3 解析记录
- [ ] 解析记录展示完整列表，不只显示最近一条。
- [ ] 点击记录可展开摘要信息。
- [ ] 长按记录可进入管理模式并自动选中。
- [ ] 管理模式支持全选/取消全选与删除。

## 6. 我的页面
- [ ] 常用设置项触控区域明显，点击反馈正常。
- [ ] X Cookie 设置入口可进入。
- [ ] 不展示“稳定模式”空按钮。
- [ ] 不展示“帮助与诊断”空卡片。

## 7. 文件名与落盘
- [ ] 同标题重复下载不覆盖，自动生成 `(1)(2)...`。
- [ ] 图片集按解析标题命名，多张图片追加顺序号。
- [ ] 下载完成文件可被系统媒体库识别。
- [ ] “已完成”只展示有效可播放结果。

## 8. 建议执行组合
- 抖音：2 条（短链/长链）
- 抖音图集：1 条（验证预览、下载全部、命名和聚合）
- X 普通视频：2 条（Cookie 有效/失效）
- X 图片：1 条（验证图片解析和保存）
- kstore hash：2 条（`bluegay`/`xgaymv`）
- AES-128 m3u8：1 条（带 key）
- 非 AES-128 m3u8：1 条（用于不支持提示校验）
