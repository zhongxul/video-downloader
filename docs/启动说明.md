# 项目启动说明

> 文档版本：v1.6.0
> 最后更新：2026-05-07

## 1. 环境要求
- Android Studio（最新稳定版）
- JDK 17（可直接使用 Android Studio 自带 JBR）
- Android SDK（项目默认路径或本机已配置路径）
- 真机或模拟器（Android 10+）

## 2. 打开项目
1. 打开 Android Studio
2. 选择 `Open`
3. 打开目录 `D:\Video Downloader`
4. 等待 Gradle Sync 完成

## 3. 终端构建（推荐）
```powershell
.\环境一键配置.ps1
.\\gradlew.bat :app:testDebugUnitTest
.\gradlew.bat :app:assembleDebug
```

产物位置：`app/build/outputs/apk/debug/app-debug.apk`

## 4. 安装到设备
优先方式：
```powershell
.\gradlew.bat :app:installDebug
```

若本机 `adb` 不在 PATH，可直接执行：
```powershell
D:\Android\Sdk\platform-tools\adb.exe devices -l
D:\Android\Sdk\platform-tools\adb.exe install -r .\app\build\outputs\apk\debug\app-debug.apk
```

若出现 `INSTALL_FAILED_UPDATE_INCOMPATIBLE`（签名不一致）：
```powershell
D:\Android\Sdk\platform-tools\adb.exe uninstall com.example.videodownloader
D:\Android\Sdk\platform-tools\adb.exe install .\app\build\outputs\apk\debug\app-debug.apk
```

## 5. 最小验证流程
1. 下载页粘贴抖音分享文案并解析，进入资源确认页。
2. 解析一条抖音图文/动图/实况图链接，确认若资源包含动态内容，下载项只生成 `_动态.mp4`。
3. 进入“我的”页面，按需保存抖音 Cookie，再回到下载页重试抖音详情解析。
4. 用一条 `kstore.vip/*.html#...` 链接（如 `bluegay/xgaymv`）解析并下载。
5. 在资源确认页验证缩略图横向切换；缩略图点击只切换选择，不应触发播放。
6. 视频资源点击主展示区播放按钮应进入 App 内播放器；返回后不应残留播放画面。
7. 点击“下载当前”或“下载全部”，观察资源库“进行中”卡片进度。
8. 下载完成后进入“资源库”：
   - 在“进行中”栏验证空状态或真实任务卡片
   - 在“进行中”栏长按卡片应进入管理模式
   - 在“已完成”栏长按卡片应进入管理并选中该条
   - 已完成列表只显示封面，合集项右上角应显示合集标识
   - 已完成详情应按纵向媒体流展示，图片点开 App 内查看器，视频点播放按钮进入 App 内播放器
9. 在“解析记录”栏确认本次解析记录存在，可点击展开摘要，长按进入管理。
10. 进入“我的”页面，确认存在 X Cookie、抖音 Cookie 设置入口和下载完成通知开关。
11. 关闭下载完成通知开关后下载完成不应弹出完成通知；重新开启后恢复。

## 6. 常见提示
- 如果 Android Studio 一直下载 `gradle-*-src.zip`：这是源码包下载，不影响命令行构建与安装。
- 如果 X 解析失败：优先检查 Cookie 是否失效、代理是否可用。
- 如果抖音图文/动图解析失败：优先检查抖音 Cookie、分享链接是否过期，以及详情接口是否被平台风控。
- 抖音动图/实况图当前只保存 `_动态.mp4`；不会生成系统相册原生实况图。
- 如果 kstore 链接失败：优先检查 `auth_key` 是否过期。
- 若出现 `unsupported m3u8 key method`：说明链接使用了非 `AES-128` 加密方式。
- 若 App 内播放器无法播放 m3u8/HLS：优先检查 Media3 依赖、源地址是否过期，以及合并文件是否通过有效性校验。

## 7. X 解析测速与定位
```powershell
D:\Android\Sdk\platform-tools\adb.exe logcat -c
D:\Android\Sdk\platform-tools\adb.exe logcat | findstr WebParserGateway
```

重点观察日志：
- `parseXFast success/fail cost=...`
- `parseXStatusFast branch=... hit=... cost=...`
- `parseTwitterFx mirror=... hit=... cost=...`
