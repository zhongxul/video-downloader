# Video Downloader（安卓本地下载）

> 文档版本：v1.6.0
> 最后更新：2026-05-07

一个仅用于个人本地使用的安卓视频下载工具，当前重点支持抖音、X，以及 `kstore.vip/*.html#...`（如 `bluegay/xgaymv`）这类 hash 包装链接的解析与下载。

## 当前实现
- 支持抖音分享文案提取链接，并通过 App 内签名详情接口解析图文、动图/实况图中的视频资源。
- 支持抖音 Cookie 设置入口，用于提升图文、动图和详情接口解析成功率。
- 支持 X 普通视频、图文混合、多视频与部分 m3u8/直播回放链接解析。
- 支持 `kstore.vip/*.html#...` 变体 Base64 hash 解码，提取真实 `mp4/m3u8` 地址。
- 支持普通 m3u8 与 `AES-128` 加密 m3u8（`#EXT-X-KEY`）下载与合并。
- 支持 m3u8/HLS 视频在 App 内通过 Media3/ExoPlayer 播放。
- 支持按清晰度、体积与可下载性对 m3u8 格式排序；同一视频只保留推荐项或默认首个视频项。
- 支持 X 链接解析提速（状态链接并行分支抢占 + 镜像并行探测）。
- 支持新 UI 三页主导航：下载工作台、资源库、信息中心。
- 支持下载队列、失败项重试、资源库管理、已完成管理。
- 支持下载前后双阶段校验，自动拦截空文件、网页内容和异常文件。
- 支持同名文件自动重命名：`标题.mp4`、`标题(1).mp4`、`标题(2).mp4`。
- 抖音动图/实况图类内容当前只保存对应的无水印 `mp4` 动态文件；不再生成实验性的额外封面或实况图文件。
- 资源库统一承接“进行中 / 已完成 / 解析记录”，三栏切换按钮固定悬浮在底部导航上方。
- 已完成集合只展示成功内容；失败详情页的重新下载只重试当前集合内失败项，成功后回填到对应已完成集合。
- 资源确认页支持多资源横向切换；缩略区只负责展示和选择，视频只通过主展示区播放按钮进入内置播放器。
- 已完成详情页按纵向媒体流展示；图片在 App 内查看，视频通过播放按钮进入内置播放器。
- 我的页接入 X Cookie、抖音 Cookie 设置入口与下载完成通知开关。

## 现状说明
- 当前解析模型仍是 `ParsedVideoInfo + List<VideoFormat>`。
- 当前下载模型仍是单 `DownloadTask`；“批量下载”和“失败组重试”基于 `parseRecordId` UI 分组实现，不是真正的 `TaskGroup + TaskItem`。
- 抖音解析已移除本地 Docker/电脑 sidecar 依赖，当前运行时只使用 App 内解析链路。
- `docs/plans/` 下的文件是后续重构方案，不代表当前已落地实现。
- `pencil-new.pen` 是 2026-05-03 新 UI 设计源文件；当前顶部栏、底部导航与资源库悬浮分段控件以代码实现为准。

## 快速开始
### Android Studio
1. 打开项目目录：`D:\Video Downloader`
2. 等待 Gradle Sync 完成
3. 运行 `app` 到真机（Android 10+）

### 终端构建
```powershell
.\环境一键配置.ps1
.\gradlew.bat :app:assembleDebug
```

APK 输出：`app/build/outputs/apk/debug/app-debug.apk`

## 常用命令
```powershell
# 构建 Debug APK
.\gradlew.bat :app:assembleDebug

# 安装到已连接设备
.\gradlew.bat :app:installDebug

# 运行单元测试
.\gradlew.bat :app:testDebugUnitTest
```
